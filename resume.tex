\section{重点项目}
\datedsubsection{\textbf{AI 客服中台}｜商汤科技}{2026.08 -- 至今}
独立设计并搭建前后端原型，支持通过对话配置客服人设、服务范围、知识库和工具，在表单中修改配置，经文本或语音试用后发布。
\begin{itemize}
  \item \textbf{客服 Agent 运行：}客服需根据会话决定直接回答、查资料、调用 HTTP 业务工具或转人工。实现多轮运行循环，装配已发布配置、历史消息与当前问题，校验工具白名单及参数，将执行结果或错误追加到消息中供模型继续决策；限制调用轮次，保存工具记录与引用。
  \item \textbf{文档分块与问答提取：}手册需保留章节上下文，FAQ 需保留问答对应。实现固定窗口、递归、标题结构、整篇与 Q\&A 分块；标题子块携带祖先标题和父级正文，超长时按 token 再切分；Q\&A 支持模板解析或模型提取，保留原段关联，分开存储检索问法与返回正文。
  \item \textbf{向量与混合检索：}用户问法与文档用词不同，错误码、字段名又需精确匹配。采用向量检索召回语义相近片段，以 BM25 补充词项匹配，按配置选择 RRF 排名融合或归一化分数加权；建库与查询使用同一 Embedding 模型，Chroma 保存向量、原文及来源。
  \item \textbf{生成式检索：}答案与适用条件分散在多篇文档时，单次召回可能遗漏上下文。设计检索 Agent 搜索、阅读与扩读原文的流程，无需预先分块或向量化；登记已读证据，\textbf{仅接受已读正文内的有效范围}，校验来源、内容哈希和行列边界。限制探索轮数与阅读预算，预算耗尽后仅允许提交证据，无相关证据可返回空结果。
  \item \textbf{系统架构与服务迭代：}按知识准备、在线服务和会话迭代组织系统，接入实时语音与渠道；为处理用户插话与人工接单，实现暂停、误判恢复、AI 退出及上下文交接。配置改进以真实会话为依据，展示建议的\textbf{差异、理由和消息引用}，经字段与版本校验、人工审核及草稿复测后发布。
\end{itemize}

\datedsubsection{\textbf{PPT Agent}｜商汤科技}{2025.01 -- 2025.07}
搭建 PPT 自动生成演示系统，实现语义 JSON 模板、生成图转 HTML 模板、整页生图后重建三种方案，处理内容与版式匹配及生成后的编辑问题。
\begin{itemize}
  \item \textbf{JSON 模板生成：}固定风格汇报需沿用原版式并在 PPT 内改稿。解析 PPTX，结合多模态模型识别页型、内容角色和逻辑关系，整理为语义 JSON 与模板树；将生成内容填入对应的标题、正文和图片位置，保留原生对象、坐标、样式和层级。大纲与幻灯片结构生成在\textbf{ 2 分钟以内}，逐页并发后按序归集。
  \item \textbf{JSON 模板匹配探索：}仅按页型选模板，难以判断内容关系与布局是否适配。实现树编码匹配原型，以手工结构特征区分关系节点与文本、图片、图表等叶子节点，经排序、空位补齐和层级衰减编码为定长向量，用余弦相似度或欧氏距离排序候选；超出宽深上限的部分会截断。
  \item \textbf{HTML 模板生成：}为扩充可复用版式，将单页或拆分后的网格视觉稿转为 HTML / CSS，提取结构与样式入库；联网搜索、抓取并整理正文，生成大纲及逐页资料，由模型选择模板并生成页面。各模块按入口组合，原生 PPTX 需另行转换。
  \item \textbf{HTML 越界检查：}为定位生成页面中的溢出元素，读取浏览器渲染后各元素的实际位置和尺寸，与页面边界比较；先检查内部元素，再检查外层容器，内部已报告越界时不重复上报容器。记录越界元素及位置，供人工或外部编排修改后重新渲染复检；重叠、可读性和内容另作视觉审阅。
  \item \textbf{整页生图与可编辑重建：}为使整页视觉图能继续改稿，用 Paddle 布局识别、OCR 和样式提取分离元素，经遮罩膨胀、LaMa 背景修复及上层遮挡处理，将图像坐标换算为幻灯片坐标，按前后层级恢复\textbf{原生文本框和独立图片}。支持按大纲逐页生图、失败重试及结果复用，也支持 PDF / 图像输入；复杂图表与插画保留为图片。检索模块已具备，资料尚未接入该方案的大纲调用。
\end{itemize}

\datedsubsection{\textbf{笔记 AI}｜商汤科技}{2024.08 -- 2024.12}
用户在笔记中查资料、追问或改写时，需要结合文档上下文与外部资料。编排 Dify 搜索工作流并实现 Python 适配层，接入联网搜索、来源引用与局部编辑。
\begin{itemize}
  \item \textbf{查询改写与搜索路由：}多轮追问常省略主题，先结合历史对话补全为独立查询，再按用户指定或自动判断的类型检索；学术类接入 arXiv，网页、科学、视频和社交类接入 SearXNG，无需搜索时返回空资料。
  \item \textbf{资料筛选与排序：}筛选需兼顾相关性、调用开销和上下文长度。原序路径去除空内容并按来源顺序截取；向量重排路径并行生成文档向量，按查询相似度阈值过滤、排序；均限制返回数量。
  \item \textbf{回答与工具输出：}同一套检索需支持直接问答及上层助手调用，因此拆分为回答和搜索工具工作流，分别返回答案及来源，或资料、搜索类型与提示。统一摘要、搜索片段和来源信息，以编号组织引用，供回答追溯出处。
  \item \textbf{选区编辑与笔记导入：}问答、改写与续写的作用范围不同，按文档、选区和指令组织上下文，分别返回答案、选区替换内容或续写增量，由笔记应用执行编辑；另参与语雀导入，将目录和内容块转为内部结构，支持已有笔记迁移。
\end{itemize}
