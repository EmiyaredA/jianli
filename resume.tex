\section{重点项目（续）}
\subsection{\textbf{PPT Agent}｜商汤科技}
围绕\textbf{内容与版式匹配、视觉表达和后续编辑}，研究并实现 PPT 语义 JSON 模板、模型生图转 HTML 模板、整页生图后直接重建三条路线；完成项目演示系统搭建，并结合模板供给、视觉要求与改稿方式分析适用场景。
\begin{itemize}
  \item \textbf{路线一｜PPT 语义 JSON 模板：}解析原始 PPTX 的元素、坐标、样式及层级，结合页面截图的多模态理解识别页面类型、内容角色和元素关系，归一化为语义 JSON 模板。将逐页结构化内容映射回原始元素，保留原生对象与样式，适用于固定风格、重复汇报及频繁改稿。
  \item \textbf{路线二｜模型生图转 HTML 模板：}将模型生成的单页或网格视觉稿拆分、转换为 HTML / CSS，提取结构定义并沉淀模板库；模型结合匹配后的模板与检索语料生成页面，通过浏览器渲染、边界检查和视觉审阅定位版式问题。以代码模板扩充视觉供给，原生 PPTX 交付另需转换。
  \item \textbf{两类模板的匹配算法：}针对语义 JSON 与 HTML 两类模板，围绕页面类型和内容结构设计匹配方案；将语料与版式统一描述为文本、图片、图表及并列、对比、递进等关系结构，按类型筛选候选并实现模型结构匹配。另探索关系树定长编码、层级衰减与余弦相似度匹配，使选版同时考虑内容组织和布局承载能力。
  \item \textbf{路线三｜整页生图与直接重建：}根据逐页内容生成完整视觉页，减少预制模板约束；通过 Paddle 布局识别、OCR 与样式提取分离文字和视觉区域，使用遮罩膨胀与 LaMa 修复背景，按坐标和层级重建原生文本框及独立图片。也支持已有 PDF / 图像输入；复杂图表与插画保留为图片。
  \item \textbf{搜索与内容规划：}实现检索词生成、网络搜索、正文抓取和信息块整理；在 HTML 模板路线中，将资料组织为大纲、逐页任务及关联语料后生成页面。结构化模板路线的大纲与幻灯片结构生成控制在\textbf{ 2 分钟以内}；整页生图路线已具备搜索模块，大纲当前仍基于用户需求生成。
  \item \textbf{模板生产与流程工程：}实现模板批量结构提取、视觉稿拆分转换和模板元信息归档，将模板准备与页面生成分开；编排逐页并发、按序归集、失败重试及中间产物留存，以任务标识关联大纲、页面与重建结果，支持生成效果对照和问题定位。
\end{itemize}

\subsection{\textbf{笔记 AI}｜商汤科技}
围绕笔记中的资料查找、文档问答与局部编辑，编排 Dify 搜索工作流并实现 Python 适配层，将检索资料转为可引用、可供上层助手使用的上下文。
\begin{itemize}
  \item \textbf{多轮查询理解与路由：}结合历史对话，将省略主题的追问改写为可独立检索的问题；校验用户指定的搜索类型，未指定时自动判断。学术类接入 arXiv，其余网页、科学、视频与社交类接入 SearXNG，无需搜索时返回空资料。
  \item \textbf{相关性与检索开销取舍：}提供原序筛选和向量重排两条路径：前者过滤空内容后保留来源顺序，后者并行生成文档向量、计算查询相似度并按阈值过滤排序；限制返回数量，按场景取舍语义相关性、模型调用开销与上下文长度。
  \item \textbf{检索与回答分层：}维护直接回答和搜索工具两类工作流，分别交付答案及来源资料、或资料与搜索类型及专用提示；统一摘要 / 搜索片段及已有元信息，按编号或来源 ID 组织引用，并适配 XML 块结构，供上层助手继续生成回答。
  \item \textbf{文档上下文与编辑适配：}结合当前文档、选区和用户指令组织任务上下文，区分问答内容、选区替换与续写增量的输出，由宿主执行替换与插入；另参与笔记格式转换与导入，实现语雀目录及内容块向内部结构的映射。
\end{itemize}
