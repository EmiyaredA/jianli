\subsection{\textbf{JAS 表格模型数据与标注}}
\textbf{项目简介：}构建并维护高质量 JAS 表格数据集及配套标注网站，支持表格模型训练数据生成、标注与质量保障。

\textbf{技术栈/方法：}JAS（JavaScript for WPS Application）、大语言模型、规则模板脚本、AI 对拍验证。
\begin{itemize}
  \item \textbf{构建并维护高质量 JAS 表格数据集。}基于种子数据集设计泛化生成策略，结合大语言模型与规则模板脚本自动生成多样化表格样本，涵盖种子数据集所有表格类型并确保样本分布均衡。
  \item \textbf{标注网站构建。}设计并实现带有 AI 对拍验证机制的文本标注系统，通过采样 K 次模型输出比对标注结果实现自动异常筛查与复审，支持多角色协作，以保障标注数据质量。
\end{itemize}

\subsection{\textbf{表格模型评测与推理结果验证}}
\textbf{项目简介：}设计模型输出自动评测与 JAS 推理结果校验流程，提升评测效率、评测一致性和自动验证准确率。

\textbf{技术栈/方法：}结构化维度评分、人工评分修正、加权评估、JAS 执行结果哈希与语义双重比对、A/B 验证与回归测试。
\begin{itemize}
  \item \textbf{数据分析模型自动评测系统的设计与实现。}对模型输出结果进行结构化维度的量化打分，并引入人工评分修正机制生成加权评估结果。系统评测与人工评分一致性达到 92.4\%，日均节省评测人力超过 4 小时，加速 A/B 验证与回归测试流程。
  \item \textbf{构建 JAS 模型推理结果自动化验证流程。}构建自动化验证系统，基于 JAS 执行结果进行哈希与语义双重比对。验证准确率由原始方案的 85.7\% 提升至 97.9\%，对格式扰动的鲁棒性显著增强。
\end{itemize}

\subsection{\textbf{GRPO 奖励函数设计}}
\textbf{项目简介：}采用 GRPO 策略提升模型生成质量，设计并集成一套基于正则匹配的奖励机制，引导模型生成包含必要结构化信息的输出结果。

\textbf{技术栈/方法：}GRPO、正则匹配、分层级关键词匹配。
\begin{itemize}
  \item 引入分层级关键词匹配策略，引导模型生成包含必要结构化信息的输出结果。
  \item 实验证明，字段命中率从原始的 70.3\% 提升至 89.6\%，整体生成准确率提升 8.4\%。
  \item 奖励机制显著降低模型输出中结构缺失与格式错误的比例，bad case 总体占比减少 10\%，有效提升收敛速度并优化后训练效果。
\end{itemize}

\subsection{\textbf{笔记项目的算法与工程支持}}
\textbf{项目简介：}为笔记应用提供智能搜索与格式转换能力，提升搜索回答可追溯性，并保障多格式笔记内容及元信息的完整迁移。

\textbf{技术栈/方法：}Perplexity 架构、查询重写、关键词与语义重排、top K 片段编号引用、HTML 映射与渲染、多格式文件解析。
\begin{itemize}
  \item \textbf{智能搜索。}基于 Perplexity 架构自研搜索流程：通过重写查询提升检索效果，结合关键词与语义重排候选结果，并融合 top K 片段生成带编号引用的回答，提升回答的可追溯性与可信度。
  \item \textbf{笔记格式转换。}支持模型生成结构化内容向前端规范 HTML 的映射，实现结果可视化渲染；同时支持主流笔记应用内容导入，通过解析多种格式文件并统一映射为内部数据结构，保障笔记内容与元信息的完整迁移体验。
\end{itemize}
