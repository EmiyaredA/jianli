\datedsubsection{\textbf{PPT Agent}｜商汤科技}{2025.01 -- 2025.07}
面向演示文稿自动制作中\textbf{版式适配、视觉表达与改稿}的需求，研究并实现语义 JSON 模板、生图转 HTML 模板、整页生图后重建三条路线，搭建演示系统，比较模板复用与视觉自由度的取舍。
\begin{itemize}
  \item \textbf{路线一｜PPT 语义 JSON 模板：}面向固定风格汇报的复用与改稿需求，解析 PPTX 结构，结合多模态理解识别页型和内容角色，形成语义 JSON 模板；映射填充内容，保留原生对象、坐标、样式与层级。
  \item \textbf{路线二｜模型生图转 HTML 模板：}为扩充可复用版式，将模型生成的单页 / 网格视觉稿拆分并转换为 HTML / CSS，提取结构定义入库；模型结合匹配模板与检索语料生成页面，以浏览器渲染、边界检查和视觉审阅定位版式问题，原生 PPTX 交付另行转换。
  \item \textbf{两类模板的匹配算法：}针对内容组织与版式承载不匹配的问题，将文本、图片、图表及并列、对比、递进关系统一为结构表示，按页型筛选候选并实现模型结构匹配；另探索关系树定长编码、层级衰减与余弦相似度，使选版同时考虑内容结构和布局。
  \item \textbf{路线三｜整页生图与直接重建：}面向定制视觉及后续改稿需求，直接生成完整视觉页，减少预制模板约束；以 Paddle 布局识别、OCR 与样式提取分离文字和视觉素材，用遮罩膨胀与 LaMa 修复背景，按坐标及层级恢复原生文本框和独立图片。支持已有 PDF / 图像，复杂图表与插画保留为图片。
  \item \textbf{搜索与内容规划：}为使页面内容有资料依据，在 HTML 路线串联检索词生成、搜索、正文抓取、信息块整理与大纲规划，按页关联语料；结构化模板的大纲与幻灯片结构生成在\textbf{ 2 分钟以内}。整页生图已具备搜索模块，大纲仍基于用户需求。
  \item \textbf{模板生产与流程工程：}针对模板重复处理和逐页生成难定位的问题，拆分模板准备与页面生成，支持批量结构提取、视觉稿转换及元信息归档；结合逐页并发、按序归集、失败重试与任务产物留存，支持模板复用和生成问题追踪。
\end{itemize}

\datedsubsection{\textbf{笔记 AI}｜商汤科技}{2024.08 -- 2024.12}
面向笔记内查资料、文档问答与局部编辑需求，编排 Dify 搜索工作流并实现 Python 适配层，将写作上下文与外部资料连接，提供可引用检索和任务输出适配。
\begin{itemize}
  \item \textbf{多轮查询理解与路由：}针对追问省略主题、不同任务所需来源不同的问题，结合历史对话改写独立查询，校验指定类型或自动分类；学术类接入 arXiv，网页、科学、视频和社交类接入 SearXNG，无需搜索时返回空资料。
  \item \textbf{相关性与检索开销取舍：}为平衡相关性、调用开销与上下文长度，提供原序筛选和向量重排：前者过滤空内容并保留来源顺序，后者并行生成文档向量，按查询相似度与阈值过滤排序；两条路径均限制返回数量。
  \item \textbf{检索与回答分层：}面向独立问答与上层助手复用两类需求，拆分直接回答和搜索工具工作流，分别返回答案及来源，或资料、搜索类型与专用提示；统一摘要 / 搜索片段和元信息，以编号或来源 ID 组织引用，适配 XML 块结构，保留回答与资料的对应关系。
  \item \textbf{文档上下文与编辑适配：}针对问答、改写与续写作用范围不同的问题，结合文档、选区及指令组织上下文，分别输出回答、替换内容和续写增量，由宿主执行编辑；另参与笔记导入，将语雀目录与内容块映射为内部结构，支持既有资料迁移。
\end{itemize}
