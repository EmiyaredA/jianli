\datedsubsection{\textbf{AI 客服中台}｜算法原型构建}{2026.08 -- 至今}
构建客服 Agent 原型：通过自然语言生成客服配置，结合知识库与业务工具处理咨询，并依据真实会话提出可审核的配置优化建议。
\begin{itemize}
  \item \textbf{Agent 运行与工具调用：}实现多轮工具调用循环，按会话装配已发布配置、历史消息和当前问题，支持知识检索、HTTP 业务工具及转人工；校验工具白名单与参数，将执行结果或错误返回模型继续决策，限制调用轮次并留存工具记录与引用。
  \item \textbf{混合检索与文档处理：}针对手册章节和 FAQ，实现标题结构、递归、固定窗口及 Q\&A 等分块，保留章节上下文与问答原段关联；融合向量检索和 BM25，支持 RRF 或分数加权，兼顾语义问法与错误码、字段名的词项匹配。
  \item \textbf{检索 Agent 与证据约束：}设计全文搜索、按需阅读及扩读流程，无需预先分块或向量化；登记已读证据，校验来源、内容哈希与行列范围，\textbf{仅接受已读原文中的有效证据}。以轮次和阅读预算限制探索，支持无相关证据时返回空结果。
  \item \textbf{人工交接与会话迭代：}接入实时语音，处理插话暂停、误判恢复及人工接单后的 AI 退出与上下文交接；基于真实会话提出配置建议，展示\textbf{差异、理由与消息引用}，经字段及版本校验、人工审核和草稿复测后发布。
  \item \textbf{检索评测：}实现基于版本化问题集与参考原文证据的评测流程，统一生成式与向量路径的查询条件和结果格式，支持证据召回、精度、全部证据命中及不可答问题的空结果判定。
\end{itemize}

\section{工作项目（续）}
\datedsubsection{\textbf{PPT Agent}｜算法原型构建}{2025.01 -- 2025.07}
搭建 PPT 自动生成演示系统，实现语义 JSON 模板、视觉稿转 HTML 模板、整页生图后重建三种方案。
\begin{itemize}
  \item \textbf{模板解析与内容生成：}解析 PPTX 并结合多模态模型识别页型、内容角色与逻辑关系，生成语义 JSON 模板；按大纲匹配模板并填充标题、正文及图片，\textbf{保留原生对象与样式}，支持逐页并发生成、按序归集。
  \item \textbf{HTML 生成与渲染检查：}将视觉稿转为可复用 HTML / CSS 模板，结合联网搜索与正文整理生成逐页资料和页面；读取浏览器渲染后的元素位置与尺寸，定位越界元素，供修改后重新渲染复检。
  \item \textbf{整页图转可编辑 PPTX：}结合 Paddle 布局识别、OCR 与样式提取分离文字和视觉素材，用遮罩膨胀及 LaMa 修复背景，按坐标与层级恢复\textbf{原生文本框和独立图片}；支持 PDF / 图像输入，复杂图表及插画保留为图片。
\end{itemize}

\datedsubsection{\textbf{笔记 AI}｜检索工作流与接口开发}{2024.08 -- 2024.12}
编排 Dify 搜索工作流并实现 Python 适配层，支持笔记内查资料、问答、改写与续写。
\begin{itemize}
  \item \textbf{查询理解与检索复用：}结合历史对话将追问改写为独立查询，按类型路由至 arXiv 或 SearXNG；实现资料筛选、向量重排及数量限制，拆分直接问答与搜索工具工作流，以编号关联回答和来源。
  \item \textbf{文档与选区编辑：}按文档、选区和指令组织上下文，分别返回答案、选区替换内容或续写增量，由笔记应用执行编辑；参与语雀导入，将目录和内容块映射为内部结构。
\end{itemize}

\datedsubsection{\textbf{数据工程}｜数据构建与自动评测}{2024.08 -- 2024.10}
\begin{itemize}
  \item \textbf{训练数据构建：}基于种子表格设计表头与数据骨架，结合大模型和规则脚本扩展业务样本，生成 Excel、任务指令与执行脚本对应数据；通过多次采样、执行对拍和人工复审筛查异常。

  \item \textbf{结构化输出校验：}实现关键字段及文本、日期、数值的提取和校验，处理格式、精度与单位差异；设计基于正则的 GRPO 分层关键词奖励，约束业务所需的结构化字段。
\end{itemize}
